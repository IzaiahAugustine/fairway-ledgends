# MakeHuman assets (CC0 1.0)

Downloaded from https://github.com/makehumancommunity/makehuman (master), `makehuman/data/`.
The MakeHuman project releases its assets (base mesh, targets, textures) under CC0 1.0
Universal; see `LICENSE.ASSETS.md` (copied from the same repository).

- `base.obj`: hm08 base mesh (`3dobjs/base.obj`). Only the head/neck faces, the eye helper spheres
  (eyeball placement) and the eyelash helper strips are used, by `golfer_mh.py`.
- `targets/*.target`: macro targets (`targets/macrodetails/`) and face detail targets
  (`targets/head`, `chin`, `cheek`, `neck`, `eyebrows`, `mouth`, `nose`), mixed with the weights
  listed in `golfer_mh.TARGETS`.
